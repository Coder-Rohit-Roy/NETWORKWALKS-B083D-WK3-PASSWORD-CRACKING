# NETWORKWALKS-B083D-WK3-PASSWORD-CRACKING
Week 3 Laboratory: Password Cracking and Hash Identification Exercises — Networkwalks Cybersecurity Internship

The objective of this project was to understand how password-protected PDF files can be analyzed in a controlled cybersecurity lab environment and how password recovery techniques can be used to evaluate password security.

---

## 📌 Project Overview

During this project, I worked with **three password-protected PDF files** provided as part of the internship task.

I used different approaches to recover the passwords:

* **John the Ripper (JtR)** on Kali Linux
* **pdf2john** for extracting password-related hash information from PDF files
* **Networkwalks Hash Calculator** as part of the provided project workflow
* PDF hash extraction and analysis

The project helped me understand the relationship between **PDF password protection, hashing, wordlists, and password recovery**.

---

## 🎯 Objectives

The main objectives of this project were:

* Understand how password-protected PDF files work
* Learn the basics of password recovery in an authorized environment
* Install and configure **John the Ripper** on Kali Linux
* Learn how `pdf2john` extracts password-related information from PDF files
* Understand the role of hashes in password security
* Use wordlists for password recovery testing
* Understand the importance of strong and unpredictable passwords
* Document the complete cybersecurity workflow
